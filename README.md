## Selected projects

### [Graded Exposure Framework](https://github.com/liamharte04/GradedExposureFramework)

Tools and design patterns for operator-controlled, graded-intensity experiences
in Unreal Engine. The repository includes a capture-to-Unreal reconstruction
pipeline and a design for an operator-controlled exposure plugin.

**Status:** Early development. The pipeline is available; the Unreal plugin is planned.

### [Kilncast](https://github.com/liamharte04/kilncast)

A Python simulation of a solar-to-methane plant, comparing rule-based and
model-predictive controllers against archived weather forecasts. Includes
constraint enforcement, reproducible experiments, tests and a replay dashboard.

**Focus:** Simulation, optimisation and forecast-aware control. Results describe
modelled behaviour, rather than measurements from a physical plant.
